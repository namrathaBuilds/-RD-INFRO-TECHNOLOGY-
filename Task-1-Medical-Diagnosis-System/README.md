# AI-Powered Medical Diagnosis System
Task 1 of AI & ML Internship at RD INFRO TECHNOLOGY.
## Objective
Develop a machine learning model to predict disease risk based on patient health parameters.
## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
## Status
Project Completed (Phase 1)
## Model Comparison

| Model | Accuracy |
|---------|---------|
| Logistic Regression | 74.8% |
| Decision Tree | 74.0% |
| Random Forest | 72.0% |

## Best Model
Logistic Regression achieved the highest accuracy of 74.8% and was selected as the final model for diabetes prediction.
## Project Outcome
Successfully developed and evaluated a machine learning model to predict diabetes risk using patient health parameters.
