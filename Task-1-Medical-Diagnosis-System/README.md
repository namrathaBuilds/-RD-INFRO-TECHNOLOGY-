# AI-Powered Medical Diagnosis System
Task 1 of AI & ML Internship at RD INFRO TECHNOLOGY.
## Objective
Develop a machine learning model to predict disease risk based on patient health parameters.
## Dataset Used
Pima Indians Diabetes Dataset
The dataset contains medical diagnostic measurements such as glucose level, blood pressure, BMI, insulin, age, and other health parameters used to predict diabetes risk.
## Project Description
This project aims to develop a machine learning model capable of predicting whether a patient is diabetic based on various health-related attributes. Multiple machine learning algorithms were trained and evaluated to determine the best-performing model.
## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
## Status
Project Completed (Phase 1)
## Model Comparison

| Model | Accuracy |
|---------|---------|
| Logistic Regression | 74.8% |
| Decision Tree | 74.0% |
| Random Forest | 72.0% |

## Best Model
Logistic Regression achieved the highest accuracy of 74.8% and was selected as the final model for diabetes prediction.
## Project Outcome
Successfully developed and evaluated a machine learning model to predict diabetes risk using patient health parameters.
## Conclusion
Three machine learning algorithms were implemented and compared for diabetes prediction. Logistic Regression achieved the highest accuracy of 74.8% and was selected as the final model. The project demonstrates the application of machine learning techniques in healthcare prediction systems.
