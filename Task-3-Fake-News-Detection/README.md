# AI-Based Fake News Detection

## Project Description
This project uses Machine Learning and Natural Language Processing (NLP) to classify news articles as Real or Fake.

## Objective
To develop an intelligent model that can identify fake news using text classification techniques.

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- NLTK
- Google Colab
- Streamlit
