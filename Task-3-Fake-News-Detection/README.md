# AI-Based Fake News Detection

## Project Description
This project uses Machine Learning and Natural Language Processing (NLP) to classify news articles as Real or Fake.

## Objective
To develop an intelligent model that can identify fake news using text classification techniques.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- NLTK
- TF-IDF Vectorizer
- Logistic Regression
- Streamlit

## Model Accuracy

**98.60%**

## Features
- Detects Real and Fake News
- Interactive Streamlit Web Application
- Machine Learning-based Prediction
- NLP using TF-IDF Vectorization
- Local Model Training Script
- User-friendly Interface
