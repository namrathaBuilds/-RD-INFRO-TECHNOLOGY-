# AI-Based Chatbot for Customer Support
## Project Description
This project focuses on developing an AI-powered chatbot that can answer customer queries using Natural Language Processing (NLP).
## Objective
Develop an intelligent chatbot capable of responding to common customer queries efficiently.
## Technologies
- Python
- NLTK
- Flask
- Google Colab
  ## Features
- Interactive web interface built using Streamlit
- Handles multiple customer support queries
- Maintains chat history
- Clear Chat functionality
- User-friendly chatbot interface
